# NOC Navigator — 單頁 CCU 排查工作台

以最少點擊找到排查線索。React / TypeScript / Vite / Tailwind CSS，無後端、無 AI API，不操作正式環境。

## 啟動

安裝 Node.js 24 LTS，在專案資料夾內執行（Windows 可用 `npm.cmd`）：

```sh
npm ci
npm run dev
npm test
npm run build
```

## 操作

1. 首頁選擇從產品、地區或機房開始，以按鈕逐步縮小範圍；改選上游會清除下游選擇。未記錄的機房對應只作候選，不推測團隊。
2. 首次篩選開始計時，右側在 5／8 分鐘顯示提示。使用時間戳計算，重新整理仍保留；可暫停、繼續、結束／重設。八分鐘出現使用者設定的正式通報流程連結，不自動通報。
3. GNM／告警／原廠工具先保留不可點擊按鈕；既有本機工具連結仍保留並依篩選顯示。外部 Downdetector 與新聞站以新分頁開啟；未確認地區不虛構網址，不嵌入第三方 iframe。VN 新聞標題需手動點擊才載入本站快照，避免首頁自動等待 RSS。
4. 右側列出今天、昨天、七天前已記錄的節假日與活動；尚未串接節假日／球賽 API，沒有紀錄不代表沒有活動。可同頁新增、編輯、刪除。
5. 點擊活動記錄 CCU 上升／下降及百分比、備註，存入本機觀察紀錄。相同活動名稱＋地區出現時帶出歷史觀察，不自動判斷因果或推定下次日期。觀察保留日期、產品、地區、方向、可空白百分比。刪除活動不刪歷史觀察。
6. 首頁不再顯示活動觀察知識庫或同頁設定區塊；原本的本機資料保留，右側活動仍可寫入觀察並查看相關歷史。維運資訊與工具需同時選擇產品及地區才顯示。既有通報網址仍可在八分鐘時開啟，未設定則顯示不可用。舊頁面路徑會導回首頁。
7. 計時器改為小型面板，新增「創群通知 · API 尚未串接」停用按鈕，沒有任何對外發送、建群或 API 呼叫。

## 私人資料與公開版

程式碼僅含合成產品示例。真實產品／機房對應應放在儲存庫外，自行保留原始 JSON；新版依需求暫時移除設定／匯入畫面，已匯入資料仍可使用。新的私人筆記不會包入原始碼、測試、截圖、Actions 或部署產物。

活動觀察中的 CCU 百分比只存瀏覽器 `noc:observations`，不發送至 GitHub 或新聞來源，不提供自動上傳或同步。localStorage 不加密，是否可存公司資料須遵循公司政策；不得保存帳密或 Token。新版不提供全資料清除畫面；需要清除可使用瀏覽器的網站資料功能，會移除所有本機紀錄。不要把任何實際觀測或內部網址放進公開原始碼。

仍保留舊 `noc:exceptions` 活動資料，新的欄位允許指定地區；舊觀察不會被捏造或自動轉成百分比。

## 部署

GitHub Settings → Pages → Source 選 **GitHub Actions**。`.github/workflows/pages.yml` 驗證、建置並部署 `dist`。HashRouter 與相對 base 支援 `/noc/` 子路徑；首頁內跳轉不更動 Router hash。沒有設定 Pages 時 deploy-pages 會回傳 404。

## 測試與維護

```sh
npm test
npm run build
# 先啟動 dev，另開終端：
npx playwright install chromium
npm run test:e2e
```

已有 Chromium 可用 `CHROMIUM_PATH=/usr/bin/chromium`；`BASE_URL` 可指定本機 `/noc/` 靜態測試站。

- `src/pages/Workbench.tsx`：單頁工作台與計時控制。
- `src/components/ActivityRail.tsx`：活動與本機觀察。
- `src/services/desk.ts`：多向篩選、計時與觀察驗證。
- `src/data/region-tools.ts`：公開地區入口，非產品基礎設施對應。
- 其他資料型別、匯入與工具服務仍可重用；舊 Wizard 元件不再掛載。

[產品資料格式](docs/data-and-flows.md)（流程部分為舊版參考） · [VN 公開新聞更新](docs/news.md)。目前未串接監控圖、正式告警、節假日／球賽資料源或 Confluence。新聞成功與否依實際快照狀態，不保證即時；也不會將背景資訊當成根因。

## 篩選示範資料

公開版內建 11 個使用者指定名稱的示範產品，地區清單用於測試按鈕；所有機房皆為假設的 `TW機房`、`SG機房`、`TH機房`，不是正式部署資訊。例：SPD → TW／TH／SG → 都只有 SG機房；DF → TW → TW機房、DF → TH → TH機房。也可先選 SG機房反查 SPD、UD、MBM、GNG。

只有完全未修改的舊 DEMO 會自動升級；自訂／私人匯入資料不會被覆蓋。首頁「載入篩選示範」可手動切換，若已有不同資料會先詢問確認；請保留原始匯入檔以便恢復。切換不清除工具、活動與觀察。
