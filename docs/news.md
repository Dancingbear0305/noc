# VN 公開新聞試用版

## 使用

到「地區查詢」選擇 `VN`，可查看新聞、依來源／主題篩選、展開來源背景。即使沒有匯入私人產品，VN 仍可選；產品清單沒有資料不影響新聞試用。其他地區顯示尚未開放，不猜測地區新聞來源。

不嵌入 iframe、不自動翻譯、不載入第三方圖片或追蹤碼。只展示標題、原文網址、來源、時間及啟發式主題。新聞是背景，不會自動寫成事件根因。時間以瀏覽器裝置時區顯示。

## 候選來源與可靠性

`src/data/news-sources.json` 定義三個候選 RSS：VnExpress International、BBC News Tiếng Việt、Việt Nam News。首次成功前只能稱為候選來源；目前雲端測試被網路白名單擋住，**尚未驗證這三個 feed URL 的實際可用性或現行 RSS 使用條款**。不要把能下載 RSS 當成獲得內容授權或內容真實性保證；上線前檢視來源的 RSS 及使用規範，不允許時移除該來源，僅保留原站入口。

國際媒體、當地主流媒體、國營通訊社旗下媒體有不同編採背景；本工具不產生虛假的可信度分數。來源維護者應檢查原始出處、更正紀錄、轉載關係及適用範圍。RSS 擷取成功只代表技術可達。BBC 越南語可能涵蓋全球新聞，不能把語言當地區，程式以公開地名關鍵字初篩所有來源。

完全相同的標題合併並保留原文入口，標示可能轉載、不等於獨立佐證；第一版不自動判斷不同標題是否同一事件。節慶／活動、電力／網路、重大突發分類為公開英越文關鍵字初篩，可能誤判或漏列。不抓取文章全文、不繞過付費牆、不做事實查核或獨立佐證判定。

## 更新與失敗處理

```sh
npm ci
npm run news:update
npm run build
```

腳本只讀公開來源清單及自身產生的 `public/news/vn.json` 快照，不接受產品／事件／特例／私密檔案作為參數，不讀取任何本機使用者資料。只讀取既有 `HTTPS_PROXY` 以遵守環境網路路徑，保留 TLS 驗證，不使用 API key。

每個來源有 20 秒總時限與 2 MB 大小上限。只接受解析正確的 RSS／Atom、HTTPS 及審查過的文章 host；不追蹤未審查重新導向、拒絕 DTD／實體宣告、移除 HTML，URL 去除 query／fragment／帳密。只留 7 天內、有時間且與 VN 公開關鍵字相關的 metadata，每來源最多 30 則。來源改網址時應手動檢查後更新 registry 與 allowlist，不放寬成全網域允許。

每次更新紀錄嘗試時間與各來源最後成功時間。部分失敗仍更新其他來源；失敗來源僅保留七天內的舊資料，明確標示舊快照。全部失敗會寫出失敗狀態並以非零結束，頁面仍可顯示失敗／舊資料。零筆符合條件不等於擷取失敗，也不捏造文章。超過 6 小時未成功會提示可能過期。

快照在 `.gitignore` 中，首次未更新／讀取失敗會顯示空狀態與來源入口。使用者按「重新讀取」僅重讀同來源本站快照，並非直接向新聞商即時查詢。

## Actions 部署

既有 Pages workflow 新增每 3 小時的排程，也能手動觸發。排程只在 GitHub 預設分支有 workflow 後運作，可能延遲，長期無活動的儲存庫也可能被 GitHub 停用排程。**目前未推送或實際執行 GitHub Actions**。

非 PR 建置先還原快取的公開 `public/news/vn.json`，再更新、快取及打包 `dist` 部署；不提交新聞快照到 Git，也不需要 contents:write。快取可能不存在或遭清除，這時不能保證保留上一次資料。更新失敗會在 Actions 摘要留提示，不阻擋網站其餘功能。PR 只跑測試與建置，不連線新聞來源或寫新聞快取。

Actions 執行環境與目前雲端的網路規則不同，需各自驗證；這次儲存雲端網域草稿不會自動發布 GitHub Pages。所需 RSS host 為 `e.vnexpress.net`、`feeds.bbci.co.uk`、`vietnamnews.vn`。

## 資料安全

使用者切換地區只在瀏覽器本機篩選，固定取得本站 `news/vn.json`，不傳送產品名稱、CCU、事件、特例提醒或私人對應。外部原文連結由使用者點開，開新分頁並使用 `no-referrer`。新增程式只允許生成公開 RSS metadata；不要擴充為自動帶入私人內容的新聞查詢。預設無示例新聞冒充真實新聞。

## 測試

`npm test` 測試公開合成 RSS／Atom、資料篩選、時間、去重、URL 安全、DTD 拒絕、失敗保留及 UI 分組。`npm run test:e2e` 使用網路攔截注入明確標示的合成快照，不讀私人資料、不依賴真實新聞商可達；涵蓋地區選擇、狀態、篩選、轉載提示與原文開啟屬性。測試通過不代表真實 RSS 可用。
